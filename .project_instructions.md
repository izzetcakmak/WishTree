# WishTree Project Instructions

## Overview
WishTree is a Web3 dApp on Arc Testnet (chain ID 5042002) for making wishes as NFTs, with Circle SDK integration for finance (swap/bridge/send), ERC-8004 AI agent registration, and a blessing (micro-donation) system.

## Technical Details
- **Chain:** Arc Testnet (5042002 / 0x4CEF52)
- **Native token:** USDC (18 decimals as gas, 6 decimals ERC-20)

## Circle SDK Integration
- Using `@circle-fin/app-kit` for swap/bridge/send operations
- Swap uses `kit.swap()` client-side (NOT server proxy) — AppKit handles approvals/execution
- Bridge uses `kit.bridge()`, Send uses `kit.send()`
- Unified Balance uses `@circle-fin/unified-balance-kit` for cross-chain balance view
- `@circle-fin/adapter-viem-v2` for MetaMask adapter
- Kit key fetched from `/api/finance/config` endpoint

## StableFX Integration
- **FxEscrow contract:** `0x867650F5eAe8df91445971f14d89fd84F0C9a9f8`
- **Permit2 contract:** `0x000000000022D473030F116dDEE9F6B43aC78BA3`
- **API:** `/api/finance/stablefx` → proxies to `https://api-sandbox.circle.com/v1/exchange/stablefx/`
- **Auth:** Uses `CIRCLE_API_KEY` env var (TEST_API_KEY for testnet)
- **Pairs:** USDC↔QCAD (CAD/USD), USDC↔EURC (EUR/USD)
- **Flow:** Permit2 approve → Quote → Trade → EIP-712 sign → Permit2 fund → Settlement
- **UI:** Amber-themed tab in finance-content.tsx, 6-step progress tracker
- **Note:** StableFX is permissioned — requires Circle KYB/AML for production
