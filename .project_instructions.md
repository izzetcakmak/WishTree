# WishTree (arcwish.xyz) — Project Instructions

## Overview
WishTree is a blockchain-based wish-making dApp on Arc Testnet (chainId: 5042002). Users write wishes that become NFTs, and an AI layer analyzes them.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Auth:** NextAuth.js (JWT + Credentials)
- **DB:** PostgreSQL + Prisma ORM
- **Blockchain:** Arc Testnet, ethers.js v5, ERC-721 (WISH NFTs), ERC-8004 (Agent Registry)
- **Smart Contract:** `0x7C51Acfdcff284c7cEc7b907ADc81948B632593a` (ArcNFTTree)
- **Finance:** Circle App Kit (Swap/Bridge/Send/Unified Balance)
- **AI:** Abacus AI LLM API (ABACUSAI_API_KEY)
- **i18n:** Zustand-based TR/EN (lib/i18n.ts)
- **Styling:** Tailwind CSS, Framer Motion, dark theme (glass morphism)

## Key Technical Patterns
- Prisma import: `import { prisma } from '@/lib/prisma'`
- Wish.id is `String @id @default(cuid())` NOT Int
- Agent.id is `String @id @default(cuid())` NOT Int
- ethers.js v5 (NOT v6) — use `ethers.providers.Web3Provider`, `ethers.utils.parseEther`, etc.
- All API routes use `export const dynamic = 'force-dynamic'`
- Wallet connection: raw MetaMask via `window.ethereum`

## Integration: WhatsApp + Bless + AI Agent (May 2026)
Three new flows added per arcwish-integration-spec.pdf:

### Flow 1: WhatsApp/SMS Wish Making
- **Webhook:** `/api/whatsapp/webhook` (Twilio)
- **Services:** `lib/services/twilio.service.ts`, `lib/services/phone-wallet.service.ts`
- Phone users get Circle developer-controlled wallets
- DB Models: `PhoneWallet`, `ProcessedMessage`

### Flow 2: USDC Blessing
- **Smart Contract:** `contracts/BlessingPool.sol` (NOT YET DEPLOYED)
- **API:** `/api/wishes/[id]/bless`, `/api/wishes/[id]/blessings`
- **Frontend:** `components/bless/BlessButton.tsx`, `BlessModal.tsx`, `BlessingList.tsx`
- Cross-chain via Circle Gateway: `/api/gateway/webhook`
- DB Models: `Blessing`, `GatewayDeposit`

### Flow 3: AI Matchmaker Agent
- **Smart Contract:** `contracts/AgentRegistry.sol` (NOT YET DEPLOYED)
- **Tick API:** `/api/agents/tick` (cron/manual trigger)
- **Service:** `lib/services/ai.service.ts` (uses Abacus AI, NOT OpenAI)
- **Frontend:** `/agents/new` page for creating matchmaker agents
- Agent model extended with: walletId, walletAddress, criteria, monthlyBudget, monthlySpent, etc.
